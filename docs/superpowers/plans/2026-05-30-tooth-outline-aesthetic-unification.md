**Goal:** Redraw all anatomy outline functions in `layout/teeth-data.jsx` to share the aesthetic language of the manually-refined wisdomU shape — smooth Bézier crown body, rounded crown-to-root transitions, blunt apices, clean interroot valleys — while preserving each tooth's correct anatomical form.

**Tech Stack:** React/JSX, SVG path strings, ShapeLab (Vite dev server at port 5174), Vitest

## Aesthetic Principles (extracted from wisdomU)

Apply these to every tooth outline:

| Principle | Description |
|-----------|-------------|
| **Smooth crown body** | Both sides bow gently outward; widest point ≈ 0.50–0.54× w at ~25–35% crown height |
| **Rounded crown shoulders** | No sharp angle where the crown side meets the cervical constriction; use a C-segment to round the transition |
| **Gentle crown base** | M point starts at y ≈ −0.012h (not y=0); closure is a shallow cubic arch, not a flat line |
| **Blunt root apex** | Every root tip: small C-curve with apex width ≈ 0.02–0.04× w; no sharp point |
| **Clean interroot valley** | For multi-root teeth: smooth V to a rounded bottom at y ≈ −0.55–0.60h |
| **Symmetric single root** | Single-root teeth: root tapers from ~0.40w at cervical to ~0.04w at apex, both sides mirror |

## Coordinate system reminder

- Origin at biting edge (y = 0). Crown is at **negative y** (upward in SVG but anatomically above the bite line).
- Left-side FDI positions are rendered via `scale(-1,1)` at runtime — never add left/right asymmetry.
- All values are normalised: `w*0.5` means 50% of tooth width from center.

1. Right crown body → right buccal root (distal) → apex
2. Up from DB apex → into palatal root → palatal apex
3. Up from palatal apex → back to interroot valley → MB root → apex
4. Up from MB apex → left crown body → crown base arch
